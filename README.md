# Hospital Ward Management System (Medipulse)

[cite_start]This repository contains the system design, prototypes, and research for the Hospital Ward Management System  [cite_start]developed for SENG 31242[cite: 5]. [cite_start]The system is designed to improve coordination between the OPD, wards, and laboratories while providing real-time patient tracking[cite: 18, 19, 20, 21, 22].

## Repository Structure

To keep the project organized, the repository is divided into the following directories:

* **/documents**: Contains formal project documentation, issue templates, and LaTeX files for the final report.
* **/prototypes**: Holds the UI/UX designs and initial front-end interface prototypes.
* [cite_start]**/research**: Contains background research, feasibility analysis, and case studies on existing platforms like OpenMRS[cite: 62].
* **/src**: Contains the main application source code (MongoDB, Express, React, and Node.js).
